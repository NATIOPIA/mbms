Features & Limitations

Every system has its strengths and constraints. Below is a summary of the core functionalities offered by the banking system, contrasted with its current limitations. This provides a balanced view of the application's capabilities.

✓ Core Features

  • 👤
    Account Management: Create, edit, search, and delete user accounts with validation.
  • 💸
    Transactions: Perform deposits, withdrawals, and transfers between accounts.
  • 📈
    Interest & Charges: Automatically calculate and apply monthly interest and service charges based on account type.
  • 🛡️
    Admin Functions: Secure admin panel to view all accounts, manage system-wide settings, and change credentials.
  • 📜
    Transaction History: View a detailed history of transactions for any account.

✗ System Limitations

  • ☝️
    Single Admin: The system is designed for only one administrator account.
  • 🌍
    No International Transfers: Functionality is limited to domestic transactions.
  • 🏦
    No Loan Facilities: The system does not include features for managing loans or credit.
  • 💰
    Daily Transfer Limit: A hard-coded daily transfer limit of 600,000 Birr is enforced.
  • ⌨️
    Console Interface: The primary user interface is text-based within a console window.
